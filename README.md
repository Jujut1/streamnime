# StreamNime - Nonton Anime Streaming

Website streaming anime dengan web scraping.

## Fitur
- Search anime
- Ongoing anime
- Genre list
- Streaming links
- Download links

## Cara Install
1. Clone repo
2. npm install
3. node server.js
4. Buka http://localhost:3000

- OtakuDesu
- Samehadaku
